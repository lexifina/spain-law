## ANEXO IV

## Clase de eficiencia energética

La clase de eficiencia energética de un aparato se determinará de conformidad con los cuadros siguientes:

Cuadro 1. Secadoras de extracción

| Clase de eficiencia energética | Consumo C de energía en kWh por kilogramo de carga de acuerdo con los métodos de ensayo mencionados en el apartado 2 del artículo 1 con el ciclo «algodón seco» |
| --- | --- |
| A | C ≤ 0,51 |
| B | 0,51 < C ≤ 0,59 |
| C | 0,59 < C ≤ 0,67 |
| D | 0,67 < C ≤ 0,75 |
| E | 0,75 < C ≤ 0,83 |
| F | 0,83 < C ≤ 0,91 |
| G | C > 0,91 |

Cuadro 2. Secadoras de condensación

| Clase de eficiencia energética | Consumo C de energía en kWh por kilogramo de carga de acuerdo con los métodos de ensayo mencionados en el apartado 2 del artículo 1 con el ciclo «algodón seco» |
| --- | --- |
| A | C ≤ 0,55 |
| B | 0,55 < C ≤ 0,64 |
| C | 0,64 < C ≤ 0,73 |
| D | 0,73 < C ≤ 0,82 |
| E | 0,82 < C ≤ 0,91 |
| F | 0,91 < C ≤ 1,00 |
| G | C > 1,00 |
