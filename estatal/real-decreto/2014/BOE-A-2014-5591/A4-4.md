## 4. Requisitos mínimos de calidad del contexto formativo.

4.1. Espacios.

Los espacios necesarios para el desarrollo de las enseñanzas de este ciclo formativo son:

‒ Aula polivalente.

‒ Taller de alojamiento.

‒ Taller de lavandería y costura.

4.2. Equipamientos mínimos.

| Aula polivalente. | Ordenadores instalados en red, cañón de proyección e Internet. Medios audiovisuales. Software de aplicación y aplicaciones informáticas. |
| --- | --- |
| Taller de alojamiento. | Dormitorio doble completo. Baño equipado. Minibar. Elementos de mobiliario y lencería para mantenimiento de alojamiento y montaje de catering |
| Taller de lavandería y costura. | Maquinaria y equipos para lavado acuoso y limpieza en seco. Maquinaria para y equipos para secado, planchado, plegado, acabado y embolsado de piezas textiles. Maquinaria y herramientas para la confección de prendas de vestir y ropa de hogar. Equipos y medios de seguridad. |
