## 4. Requisitos mínimos de calidad del contexto formativo.

4.1. Espacios.

Los espacios necesarios para el desarrollo de las enseñanzas de este ciclo formativo son:

‒ Aula polivalente.

‒ Planta de elaboración.

‒ Laboratorio.

‒ Taller de almacenaje.
