## ANEXO

## Aplicación telemática para la cumplimentación y presentación telemática de solicitudes de clasificación de empresas

1. Plataforma Tecnológica de Desarrollo:

ASP.NET, VB.NET, HTML 4.0, Javascript, Web Services

2. Acceso y Transporte:

HTTPS/SSL

3. Requisitos mínimos para el sistema del usuario:

3.1 Sistema operativo:

Windows 98 o superior

3.2 Navegación:

Internet Explorer, versión 5.01 o superior.

Admitir la apertura de ventanas «pop-up».

3.3 Impresión de formularios:

Acrobat Reader, versión 7 o superior.

3.4 Firma Digital:

Certificado electrónico conforme con lo dispuesto en el apartado Segundo b) de la Orden.

Tener instalado CAPICOM 2.0 o superior.
