## ANEXO I

## Bandas de consumo

De conformidad con el Reglamento (UE) 2016/1952 del Parlamento Europeo y del Consejo, de 26 de octubre de 2016, las bandas de consumo en que se desagregan los precios para los clientes domésticos son las siguientes:

| Banda de consumo | Consumo anual de electricidad (kWh) |
| --- | --- |
| Mínimo | Máximo |
| Banda DA. |  | < 1.000 |
| Banda DB. | ≥ 1.000 | < 2.500 |
| Banda DC. | ≥ 2.500 | < 5.000 |
| Banda DD. | ≥ 5.000 | < 15.000 |
| Banda DE. | ≥ 15.000 |  |

Las bandas de consumo en que se desagregan los precios para los clientes no domésticos son las siguientes:

| Banda de consumo | Consumo anual de electricidad (MWh) |
| --- | --- |
| Mínimo | Máximo |
| Banda IA. |  | < 20 |
| Banda IB. | ≥ 20 | < 500 |
| Banda IC. | ≥ 500 | < 2.000 |
| Banda ID. | ≥ 2.000 | < 20.000 |
| Banda IE. | ≥ 20.000 | < 70.000 |
| Banda IF. | ≥ 70.000 | < 150.000 |
| Banda IG. | ≥ 150.000 |  |
