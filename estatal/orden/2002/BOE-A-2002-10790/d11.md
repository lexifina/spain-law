## D11. Rendimientos implícitos y diferencias negativas entre los valores de reembolso y emisión de la Deuda del Estado. Euros.

Con el siguiente formato de columnas:

| DESCRIPCIÓN DE LAS COLUMNAS |
| --- |
| Denominación de la Deuda. |
| Fecha de emisión. |
| Importe de emisión. |
| Fecha de reembolso. |
| Importe de reembolso. |
| Importe total de la diferencia entre el valor de reembolso y el valor de emisión |
| Importe de bajas y rectificaciones. |
| Importe de rendimientos implícitos devengados en ejercicios anteriores. |
| Importe de rendimientos implícitos devengados en el ejercicio. |
| Importe de rendimientos implícitos pendientes de devengo al 31 de diciembre. |
| Importe de diferencias negativas devengadas en ejercicios anteriores. |

| Importe de diferencias negativas pendientes de devengo al 31 de diciembre. |
